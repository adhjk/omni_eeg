# 修复视觉想象实验问题

## 问题分析

### 问题1：实验1.1 被动想象中，点击空格无法暂停而是会退出实验页面

**根本原因**：
- `visual_window.py` 的 `on_space` 回调会调用实验代码中的 `pause_callback`
- `sleep_with_recording` 函数中，当暂停时会进入 `while recorder.is_paused` 循环等待恢复
- 这个循环会阻塞 Streamlit 的主线程，导致页面无响应或超时退出

### 问题2：实验1.2 主动想象中，停止实验后无法继续

**根本原因**：
- `VisualStimulusWindow` 是单例类，`__init__` 中检查 `_initialized` 标志跳过重新初始化
- `run` 函数的 `finally` 块调用 `window.close()` 而非 `window.destroy()`，线程未真正销毁
- `start()` 方法检测到线程仍在运行，直接返回，导致队列状态混乱

### 问题3：实验时长控制

**当前配置**：
- `trials_per_hour = 900`，`session_hours = 4`
- 每个 trial：图片展示 1s + 十字遮罩 0.5s + 回忆 2s + 休息 0.5s = 4s
- 理论：900 × 4s = 3600s = 1小时
- 实际：队列处理、线程切换等开销导致偏差

## 修复方案

### 1. 修改 `visual_window.py`：改进暂停机制

**目的**：让暂停回调在独立线程中执行，避免阻塞

**修改内容**：
- 在 `on_space` 回调中，使用 `threading.Thread` 包装 `pause_callback` 调用
- 确保 `_is_paused` 状态正确同步

### 2. 修改 `visual_exp_1_1.py` 和 `visual_exp_1_2.py`：修复暂停逻辑

**目的**：正确处理暂停期间的时间计算

**修改内容**：
- 修改 `sleep_with_recording` 函数，在暂停期间保存剩余时间而非重置
- 确保暂停时不丢失已过时间

### 3. 修改 `visual_exp_1_1.py` 和 `visual_exp_1_2.py`：修复停止后无法继续的问题

**目的**：确保实验停止时彻底清理窗口资源

**修改内容**：
- 在 `finally` 块中调用 `window.destroy()` 而非 `window.close()`
- 或者在 `run` 函数开始时重置窗口状态

### 4. 调整实验时长参数

**目的**：确保单次实验耗时约4小时

**修改内容**：
- 检查并确认 `trials_per_hour` 和 `session_hours` 参数
- 添加时间校准逻辑，确保实际运行时间符合预期

## 实施步骤

### 步骤1：修改 `visual_window.py`

```python
# 在 on_space 函数中添加线程包装
def on_space(_event=None) -> None:
    self._is_paused = not self._is_paused
    debug_log(f"空格键被按下，暂停状态: {self._is_paused}")
    if self._pause_callback is not None:
        try:
            # 使用线程避免阻塞 Tkinter 主循环
            threading.Thread(
                target=self._pause_callback,
                args=(self._is_paused,),
                daemon=True
            ).start()
        except Exception as e:
            debug_log(f"暂停回调执行失败: {e}")
```

### 步骤2：修改 `visual_exp_1_1.py` 和 `visual_exp_1_2.py` 的 `sleep_with_recording`

```python
def sleep_with_recording(duration_sec: float) -> None:
    remaining = max(float(duration_sec), 0.0)
    start = time.monotonic()
    while remaining > 0:
        flush()
        refresh()
        if recorder.is_paused:
            console.print("[bold yellow]实验已暂停，按空格键继续[/bold yellow]")
            paused_start = time.monotonic()
            while recorder.is_paused:
                flush()
                refresh()
                time.sleep(0.02)
            console.print("[bold green]实验继续[/bold green]")
            # 暂停期间不消耗剩余时间
            paused_duration = time.monotonic() - paused_start
            start += paused_duration
        elapsed = time.monotonic() - start
        remaining = max(float(duration_sec) - elapsed, 0.0)
        time.sleep(min(0.02, remaining))
    flush()
    refresh()
```

### 步骤3：修改 `visual_exp_1_1.py` 和 `visual_exp_1_2.py` 的 `finally` 块

```python
finally:
    try:
        acquirer.stop_stream()
    except Exception:
        pass
    try:
        # 使用 destroy() 彻底销毁窗口，允许重新创建
        window.destroy()
    except Exception:
        pass
```

### 步骤4：调整实验时长参数（确保4小时）

当前配置已满足：
- 每个 trial：4秒
- 900 trials/小时：900 × 4 = 3600秒 = 1小时
- 4小时：4 × 900 = 3600 trials
- 休息时间：每小时5分钟，共3次休息 = 15分钟

总计：4小时15分钟 ≈ 4小时
