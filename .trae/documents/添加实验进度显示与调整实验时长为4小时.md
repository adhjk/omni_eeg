# 添加实验进度显示与调整实验时长为4小时

## 目标
1. 在视觉刺激窗口右上角添加实验进度显示（格式："当前trial/总trial"）
2. 将两种实验的单次实验时间调整为约4小时，每小时后有5分钟休息

## 技术方案

### 1. 修改视觉刺激窗口（visual_window.py）
- 在窗口右上角添加进度显示标签
- 添加 `set_progress(current, total)` 方法更新进度显示

### 2. 修改被动想象实验（visual_exp_1_1.py）
- 将每张图片的trial次数从1000次调整为180次（20×180=3600个trial）
- Trial结构：图片1s + 十字0.5s + 回忆2s + 休息0.5s = 4s/trial
- 3600个trial × 4s = 14400s = 4小时
- 在每个trial后调用进度更新方法

### 3. 修改主动想象实验（visual_exp_1_2.py）
- 同样调整trial数量为3600个
- 在每个trial后调用进度更新方法

### 4. 修改协议配置（passive_visual_protocol.py 和 active_visual_protocol.py）
- 修改 trial_order 构建函数的默认参数

## 具体修改

### 文件列表
1. `tasks/visual_window.py` - 添加进度显示标签和方法
2. `tasks/visual_exp_1_1.py` - 调整trial数量并添加进度更新
3. `tasks/visual_exp_1_2.py` - 调整trial数量并添加进度更新
4. `adaptation/passive_visual_protocol.py` - 更新默认参数
5. `adaptation/active_visual_protocol.py` - 更新默认参数

### 计算依据
- 目标实验时间：4小时 = 14400秒
- Trial时长（被动）：1+0.5+2+0.5 = 4秒
- 总trial数：14400 / 4 = 3600个
- 20张图片，每张：3600 / 20 = 180次
- 休息安排：第1、2、3小时后各休息5分钟（共15分钟）
- 总计实验时间：约4小时15分钟（含休息）
